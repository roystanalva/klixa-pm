# Klixa ERP

Enterprise-grade resource planning platform built for scale, speed, and collaboration.

## Modules

| Module        | Description                              |
|---------------|------------------------------------------|
| **Dashboard** | Executive KPIs, charts, tasks, activity  |
| **Finance**   | Transactions, budgets, revenue tracking  |
| **Procurement** | Purchase orders, vendor management     |
| **Inventory** | Stock tracking, warehouse management     |
| **Sales**     | Orders, customers, revenue analytics     |
| **HR**        | Employee directory, department overview  |
| **Reports**   | Analytics dashboards, downloadable reports |
| **Approvals** | Workflow-based approval center           |
| **Settings** | Roles, permissions, audit logs, integrations |

## Tech Stack

- **Framework**: React 19 + TypeScript
- **Build Tool**: Vite
- **Routing**: React Router v7
- **Charts**: Recharts
- **Icons**: Lucide React
- **Styling**: Custom CSS design system with CSS variables

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Design

- Original enterprise UX with custom component library
- Professional color palette (navy/teal primary, slate neutrals)
- Light and dark mode support
- Responsive layouts for desktop, tablet, and mobile
- Keyboard-accessible with WCAG-friendly contrast
- Data-dense tables with sorting, pagination, and filtering
- Master-detail views with slide-out drawers and modals
